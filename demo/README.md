### How to Take Screenshots

1. Install @lisp in CAD (see [README](../README.md))
2. Run `C:@P` to open Package Manager
3. Run `C:@C` for AI Chat
4. Run `C:@@` for Command Panel
5. Use CAD's `_JPGOUT` or `_PNGOUT` to capture, or use any screen capture tool

### How to Record GIF

1. Use [ScreenToGif](https://www.screentogif.com/) (Windows, free)
2. Record a 15-30 second workflow
3. Optimize: max 5MB, 800px wide
4. Name as `*-demo.gif` and place in this directory
