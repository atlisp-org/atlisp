# B站 @lisp 入门教程系列

## 第1集：30秒安装 @lisp

**时长**: 3-5 分钟  
**目标**: 让观众从零开始，在 CAD 中完成安装

```
时间线:
0:00  开场 — @lisp 是什么？
0:30  CAD 中输入一行代码
1:00  完成安装，看到 @lisp 菜单
1:30  快速体验：打开命令面板 (C:@@)
2:30  查看已安装的包 (@L)
3:00  总结 + 下集预告
```

**关键画面**:
- 代码复制 → 粘贴到 CAD → 安装过程 → 菜单出现

## 第2集：安装并使用第一个包

**时长**: 5-7 分钟  
**目标**: 展示包管理的完整流程

```
时间线:
0:00  回顾上集
0:30  @I 命令安装包（如 at-arch）
1:30  包自动下载、加载
2:00  使用包的功能
3:30  浏览包列表 (@P)
4:30  卸载包 (@R)
5:30  总结
```

**演示包建议**: `at-layer`（图层管理，效果直观）

## 第3集：AI 助手帮你写代码

**时长**: 5-8 分钟  
**目标**: 展示 C:@C AI 聊天功能

```
时间线:
0:00  什么是 @lisp AI？
0:30  启动聊天: C:@C
1:00  自然语言生成 LISP 代码
   "画一个圆心在 (100,100) 半径为 50 的圆"
2:00  AI 生成代码并自动执行
3:00  更多例子: 批量操作、条件判断
5:00  AI 辅助学习 LISP
6:00  总结
```

## 第4集：自定义你的 CAD 环境

**时长**: 5-7 分钟  
**目标**: 配置管理、快捷键、菜单定制

```
时间线:
0:00  @S 打开设置
0:30  修改常用配置（快捷键、自动更新）
2:00  安装侧边栏包 (at-sidebar)

4:30  多包组合使用

```
