# @lisp 约束条件配置

## 一、安全约束

### 禁止操作
```
禁止: 泄露 token、密码、授权码
禁止: 删除生产数据
禁止: 执行危险命令 (rm -rf, format, dd)
禁止: 修改系统配置
禁止: 访问未授权的资源
```

### 必须操作
```
必须: 使用环境变量存储敏感信息
必须: 操作前备份重要数据
必须: 记录所有敏感操作
必须: 验证操作结果
```

## 二、代码约束

### 编码约束
```
必须: 使用 UTF-8 编码
禁止: 使用 GB2312/ANSI 编码
必须: 函数有文档注释
必须: 变量已声明
```

### 格式约束
```
必须: 行长度 ≤ 100 字符
必须: 括号匹配
禁止: 尾部空格
必须: 缩进一致 (2空格)
```

### 命名约束
```
必须: 函数名 namespace:functionname
必须: 命名空间与目录名一致
必须: 全局变量用 *...* 包围
禁止: 使用保留字
```

## 三、质量约束

### 测试约束
```
必须: 新函数有测试
必须: 测试覆盖边界条件
必须: 测试通过才能提交
禁止: 跳过测试
```

### 文档约束
```
必须: 函数有 docstring
必须: 包有 README
必须: 重大变更更新 CHANGELOG
禁止: 提交无文档的代码
```

### 性能约束
```
禁止: 循环内字符串拼接
禁止: 无意义的递归
必须: 复杂度分析
建议: 性能测试
```

## 四、流程约束

### 提交约束
```
必须: 提交前运行 lint
必须: 提交前运行测试
必须: 提交信息清晰
禁止: 提交敏感信息
```

### 审查约束
```
必须: 代码审查后才能合并
必须: 审查意见已处理
必须: 测试通过
禁止: 跳过审查
```

### 发布约束
```
必须: 版本号规范
必须: 更新 CHANGELOG
必须: 测试通过
必须: 文档完整
```

## 五、资源约束

### 时间约束
```
单个任务: ≤ 4小时
单次操作: ≤ 30分钟
超时处理: 升级或暂停
```

### 空间约束
```
日志文件: ≤ 100MB
临时文件: ≤ 1GB
备份文件: ≤ 10个版本
```

### 依赖约束
```
必须: 检查依赖版本
必须: 锁定依赖版本
禁止: 使用过期依赖
建议: 定期更新依赖
```

## 六、沟通约束

### 汇报约束
```
必须: 完成任务后汇报
必须: 遇到问题及时反馈
必须: 提供清晰的操作记录
禁止: 隐瞒问题
```

### 协作约束
```
必须: 尊重其他开发者
必须: 清晰的沟通
必须: 及时响应
禁止: 推卸责任
```

## 七、异常约束

### 异常处理约束
```
必须: 捕获所有异常
必须: 记录异常日志
必须: 通知相关人员
禁止: 忽略异常
```

### 恢复约束
```
必须: 验证恢复结果
必须: 记录恢复过程
必须: 分析异常原因
禁止: 重复异常
```

---

*遵循这些约束，确保工作质量和安全。*
