# @lisp 持续学习机制配置

## 一、学习类型

### 知识学习

```
类型: 项目知识、技术知识、业务知识
来源: 代码、文档、日志、反馈
方式: 分析、总结、归纳
存储: 知识库、经验库
```

### 技能学习

```
类型: 编码技能、调试技能、优化技能
来源: 任务执行、问题处理、代码审查
方式: 实践、模仿、创新
存储: 技能库、模板库
```

### 经验学习

```
类型: 成功经验、失败教训、最佳实践
来源: 任务完成、问题解决、用户反馈
方式: 总结、提炼、应用
存储: 经验库、案例库
```

## 二、学习流程

### 学习流程

```
1. 信息收集
   - 收集任务信息
   - 收集用户反馈
   - 收集系统日志

2. 信息分析
   - 分析成功因素
   - 分析失败原因
   - 分析改进空间

3. 知识提炼
   - 总结规律
   - 提炼方法
   - 形成规则

4. 知识应用
   - 应用到新任务
   - 优化现有流程
   - 改进决策能力

5. 知识存储
   - 更新知识库
   - 更新经验库
   - 更新技能库
```

### 反馈学习

```
1. 接收反馈
   - 用户反馈
   - 系统反馈
   - 测试反馈

2. 分析反馈
   - 识别问题
   - 分析原因
   - 评估影响

3. 生成改进
   - 制定改进方案
   - 实施改进措施
   - 验证改进效果

4. 记录学习
   - 记录改进过程
   - 记录改进结果
   - 更新知识库
```

## 三、学习规则

### 学习优先级

```
高优先级:
- 生产环境问题
- 用户高频反馈
- 核心功能异常

中优先级:
- 性能优化问题
- 代码质量问题
- 文档更新需求

低优先级:
- 代码规范问题
- 体验优化建议
- 工具改进需求
```

### 学习频率

```
实时学习:
- 错误处理经验
- 用户反馈处理

每日学习:
- 任务完成总结
- 代码质量分析

每周学习:
- 最佳实践总结
- 技能提升计划

每月学习:
- 知识库更新
- 经验库整理
```

## 四、知识库管理

### 知识库结构

```
knowledge/
├── project/          # 项目知识
│   ├── architecture.md  # 架构知识
│   ├── modules.md       # 模块知识
│   └── dependencies.md  # 依赖知识
├── technical/        # 技术知识
│   ├── coding.md        # 编码知识
│   ├── debugging.md     # 调试知识
│   └── optimization.md  # 优化知识
├── business/         # 业务知识
│   ├── requirements.md  # 需求知识
│   ├── workflows.md     # 流程知识
│   └── users.md         # 用户知识
└── experience/       # 经验知识
    ├── successes.md     # 成功经验
    ├── failures.md      # 失败教训
    └── best-practices.md # 最佳实践
```

### 知识更新规则

```
IF 新知识产生 THEN
    检查是否已有类似知识
    IF 已有 THEN
        更新现有知识
    ELSE
        创建新知识

IF 知识过期 THEN
    标记为过期
    归档或删除

IF 知识冲突 THEN
    分析冲突原因
    选择最佳知识
    更新知识库
```

## 五、经验库管理

### 经验记录格式

```markdown
# 经验记录

## 基本信息
- 任务类型: Bug修复/新功能/优化
- 执行时间: YYYY-MM-DD
- 执行结果: 成功/失败/部分成功

## 经验详情
- 问题描述: [问题]
- 解决方案: [方案]
- 关键点: [关键点]
- 注意事项: [注意事项]

## 应用场景
- 适用场景: [场景]
- 不适用场景: [场景]

## 相关经验
- 相关经验1: [链接]
- 相关经验2: [链接]
```

### 经验应用规则

```
IF 新任务与历史任务相似 THEN
    参考历史经验
    应用成功方案
    避免失败教训

IF 任务复杂度高 THEN
    查找类似案例
    借鉴解决方案
    创新改进方案
```

## 六、技能库管理

### 技能分类

```
基础技能:
- 代码编写
- 问题定位
- 测试验证

高级技能:
- 架构设计
- 性能优化
- 代码重构

专家技能:
- 系统设计
- 技术决策
- 团队指导
```

### 技能提升规则

```
IF 基础技能熟练度 > 80% THEN
    开始学习高级技能

IF 高级技能熟练度 > 80% THEN
    开始学习专家技能

IF 技能使用频率 < 10% THEN
    保持当前水平
    定期复习巩固
```
