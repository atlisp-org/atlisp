# Bug 修复助手

## 修复流程

1. 理解问题
2. 定位原因
3. 制定方案
4. 实施修复
5. 验证测试
6. 提交代码

## 命令

```bash
# 查看错误日志
cat logs/sync.log
cat logs/lint.log

# 运行测试
cd lib && make test

# 检查代码
make lint
```

## Bug 分类

### 高优先级
- 功能完全失效
- 数据丢失
- 安全漏洞

### 中优先级
- 功能异常
- 性能问题
- 兼容性问题

### 低优先级
- 界面问题
- 文档错误
- 代码规范

## 修复模板

```markdown
# Bug 修复报告

## 问题描述
- 现象: xxx
- 复现步骤: xxx
- 影响范围: xxx

## 原因分析
- 根本原因: xxx
- 触发条件: xxx

## 修复方案
- 修改文件: xxx
- 修改内容: xxx
- 测试结果: xxx

## 验证
- [ ] 功能正常
- [ ] 测试通过
- [ ] 无副作用
```

## 注意事项

- 先理解再修改
- 修复要彻底
- 测试要充分
- 记录要完整
