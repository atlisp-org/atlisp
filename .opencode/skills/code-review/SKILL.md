# 代码审查助手

## 审查流程

1. 运行 lint 检查
2. 检查代码规范
3. 验证测试覆盖
4. 生成审查报告

## 命令

```bash
# 运行 lint 检查
make lint
make lint-projects

# 检查暂存区
make lint-staged

# 自动修复
make lint-fix
```

## 审查清单

### 代码质量
- [ ] 括号匹配
- [ ] 行长度 ≤ 100 字符
- [ ] 无尾部空格
- [ ] UTF-8 编码

### 函数规范
- [ ] 有文档注释
- [ ] 参数已声明
- [ ] 返回值明确
- [ ] 错误处理完善

### 测试覆盖
- [ ] 有测试用例
- [ ] 测试通过
- [ ] 边界条件测试

## 审查报告模板

```markdown
# 代码审查报告

## 文件: xxx.lsp

### 优点
- 代码结构清晰
- 注释完整

### 问题
1. **严重**: 缺少错误处理
2. **一般**: 行长度超限
3. **建议**: 变量命名不规范

### 建议
- 添加 try-catch 错误处理
- 拆分长行代码
- 使用更具描述性的变量名
```

## 注意事项

- 客观公正地评价
- 提出具体改进建议
- 肯定代码的优点
- 关注可维护性
