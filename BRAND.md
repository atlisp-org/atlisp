# @lisp Brand Assets

## Logo

| Variant | File |
|---------|------|
| Vector (SVG) | `vscode/images/atlisp.svg` |
| Bitmap (256x256) | `vscode/images/atlisp-256.png` |
| Bitmap (full) | `vscode/images/atlisp.png` |
| GIMP source | `vscode/images/atlisp.xcf` |

### Logo Usage
- **Minimum clear space**: 1/4 of logo height on all sides
- **Background**: Use on white or light backgrounds. For dark backgrounds, add a white container or use the dark variant.
- **Do not**: Stretch, rotate, change colors, or add effects.

## Brand Colors

| Color | Hex | Usage |
|-------|-----|-------|
| Primary Red | `#E63946` | Logo, headings, accent |
| Dark | `#1D3557` | Text, headers |
| Light BG | `#F1FAEE` | Page backgrounds |
| Accent Blue | `#457B9D` | Links, buttons |
| Muted | `#A8DADC` | Secondary elements |

## Typography

- **Primary font**: Microsoft YaHei (中文) / Inter (English)
- **Code font**: JetBrains Mono / Consolas
- **CAD commands**: `C:@@`, `@I`, `@L` — always in backticks
